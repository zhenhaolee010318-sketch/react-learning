# Zustand 状态管理

Zustand 是一个轻量级、类型安全的状态管理解决方案，非常适合 React 应用。

## 核心知识点

### 1. Store 创建

使用 `createStore` 创建 Zustand store，定义状态和更新方法。

```typescript
export const createUserStore = createStore<UserStore>(set => ({
    user: null,
    setUser: (user: User) => set({ user })
}))
/**
 * 这里呢 要注意的是 createStore 和craete的区别
 * 
 * create 是直接复用了 createStore 和 useStore 的 api ，
 * 而 createStore 是创建一个 store ，useStore 是使用一个 store。
 * 只用useStore 才能 动态的监听到 store 的变化。
*/
```

### 2. Context 集成

通过 React Context 将 Zustand store 注入到组件树中，实现依赖注入模式。

```typescript
export const UserContext = createContext<TaskStoreApi | null>(null)

export const UserProvider = ({ children }: { children: React.ReactNode }) => {
    const [store] = useState(createUserStore)
    return (
        <UserContext.Provider value={store}>
            {children}
        </UserContext.Provider>
    )
}
```

### 3. 类型安全

使用 TypeScript 定义 Store 接口，确保状态更新的类型安全。

```typescript
export interface UserStore {
    user: User | null;
    setUser: (user: User) => void;
}
```

### 4. 选择器模式

使用选择器函数精确订阅 store 的特定部分，避免不必要的重渲染。

```typescript
const selectUser = (state: UserStore) => state.user;
const user = useUser(selectUser);
```

## 优势

- **轻量级**：体积小，API 简洁
- **类型安全**：完整的 TypeScript 支持
- **灵活**：可以与 Context API 结合使用
- **性能好**：精确的订阅机制，避免不必要的重渲染

## 使用示例

```typescript
// 在组件中使用
const user = useUser(selectUser);
const setUser = useUser(selectSetUser);

useEffect(() => {
    setUser({
        name: "Jonh",
        age: 20,
        email: "jon@gmail.com"
    });
}, [setUser]);
```
### 5. 对比其他的 中间件 比如 Redux
1. Redux 写起来十分的繁琐，需要写很多的样板代码。
- [1] 需要去定义一个initial state。
- [2] 然后的话需要去配置 reducer 函数，来进行state的更改， prev -> new state
- [3] 接着createSlice 去生成一个slice的配置，用于在 createStore中使用
- [4] 最后的话需要去配置一个 store ，用于在 createStore中使用

、、、
```typescript
const initialState = {
    count: 0
}

export const counterSlice = createSlice({
  name: 'counter',  // slice 的名字
  initialState,
  // reducers 字段定义了如何更新状态
  reducers: {
    increment: (state) => {
      // RTK 内部使用 Immer，允许我们“直接修改”状态
      state.value += 1;
    },
    decrement: (state) => {
      state.value -= 1;
    },
    incrementByAmount: (state, action) => {
      state.value += action.payload; // payload 是 action 携带的数据
    },
  },
});

生成一个store的配置，用于在 createStore中使用
// store/store.js
import { configureStore } from '@reduxjs/toolkit';
import counterReducer from './counterSlice'; // 导入上一步的 reducer

export const store = configureStore({
  reducer: {
    counter: counterReducer, // 将 counter slice 添加到 store
    // 未来可以添加其他 slice，如 user: userReducer
  },
});
```
但是之后再使用的时候，很麻烦 你得先 通过Provider store 去注入到组件树中，才能使用。
```typescript
<Provider store={store}>
  <App />
</Provider>
```
然后才可以去 使用 store 中的数据。
```typescript
const count = useSelector((state: RootState) => state.counter.value);
const dispatch = useDispatch();
```
必须得搭配着 useSelector 和 useDispatch 去使用。 


## 最佳实践

1. **使用选择器**：总是使用选择器函数来订阅状态，而不是直接访问整个 store
2. **类型定义**：为每个 store 定义清晰的 TypeScript 接口
3. **Context 模式**：使用 Context 模式可以更好地进行依赖注入和测试
4. **避免过度使用**：对于简单的本地状态，优先使用 `useState`
